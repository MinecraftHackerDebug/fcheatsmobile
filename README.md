# FCheats mobile

## Why use FCheats mobile?
Unlike most FC Mobile cheats, this on is legit. It usually has updates and will have bug fixes every so often.
It has safety features, ensuring a lower risk of getting banned.

### Version 1.0
This version is still new. Errors are to be expected and can be reported. If you find a bug, please go to the releases and comment there.
Does not have a high or low chance to get you banned, but cannot be overused or there can be a high ban risk
Version 1.0 does use a simple safety feature that is not possible to disable unless you change the code. Still being worked on.
